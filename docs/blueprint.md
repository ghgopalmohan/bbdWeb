# **App Name**: Gopal Mohan Portfolio

## Core Features:

- Hero Section: Home/Hero Section: Showcase intro text, background animation, and a 'See My Work' call-to-action button.
- About Section: About Me: Animated text introduction and a timeline section displaying 25+ years of design experience.
- Portfolio Display: Portfolio: Filterable grid layout with lightbox previews, displaying work samples (cards, menus, pamphlets, banners, etc.).
- Services Offered: Services: Icon and text blocks outlining service offerings (cards, menus, banners, brochures) with animated hover effects.
- Testimonials Carousel: Testimonials: Carousel displaying client testimonials with star ratings or quotes.
- Contact Form: Contact Me: Contact form with floating labels and animated icons linking to professional profiles (LinkedIn, Instagram, Email).
- Dark/Light Mode: Include a toggle button in the header for dark/light mode.

## Style Guidelines:

- Primary color: Deep violet (#673AB7) for a professional and creative impression.
- Background color: Very light grey (#F5F5F5) for a clean and modern backdrop.
- Accent color: Light purple (#BB86FC) for hover effects and call-to-action highlights.
- Body font: 'PT Sans', a versatile humanist sans-serif, for body text.
- Headline font: 'Playfair', an elegant modern serif font, for headlines.
- Use professional, minimalist icons for services and contact links.
- Employ a clean and modern layout with generous white space for readability.
- Incorporate subtle scroll animations and hover effects to enhance user experience.
